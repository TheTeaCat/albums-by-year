# Albums By Year

I wanted to see my saved albums on Spotify categorised by year. I had a google only to find a [6 year old feature request](https://community.spotify.com/t5/Live-Ideas/Your-Music-Sort-Music-in-quot-Your-Music-quot-by-Year/idc-p/4954954/highlight/true#M194761).



## Archival Notice ⚠️

After over half a decade, I'm archiving this project. It uses the [Implicit Grant Flow](https://developer.spotify.com/documentation/web-api/tutorials/implicit-flow), which was deprecated by Spotify on 27th November 2025 according to the email I received from them on 14th October.

[Spotify has been airing ICE recruitment adverts and its CEO has invested heavily in Helsing, a military AI company](https://www.rte.ie/brainstorm/2025/1114/1543919-spotify-boycott-protests-artists-fans-music-streaming-models/). Consequently, I have no interest in maintaining a project integrating with their service.

The project will remain available in a demo state at [albumsbyyear.rainosullivan.com](https://albumsbyyear.rainosullivan.com/).




## Development Quickstart

```bash
git clone git@github.com:TheTeaCat/albums-by-year.git
cd albums-by-year
bun install
bun run serve
```
